"SpendWise – Spend wisely, track wisely"

SpendWise is a full-stack expense tracking web application built with the MERN stack and GraphQL. It allows users to log and categorize their transactions — savings, expenses, and investments — and visualize their financial breakdown through an interactive donut chart. Secured with JWT authentication and deployed end-to-end on Vercel.

"Features"

User authentication with JWT — secure login and session management
Add and categorize transactions as savings, expenses, or investments
Interactive donut chart for real-time financial breakdown visualization
Full transaction history with date, location, and payment type tracking
GraphQL API with optimized resolvers to eliminate data over-fetching
Role-based access control for secure data handling
Fully responsive and mobile-friendly UI
